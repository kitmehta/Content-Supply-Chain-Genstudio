# Content Supply Chain – GenStudio Engagement Training

An interactive eLearning course walking delivery teams through Adobe's end-to-end **GenStudio engagement methodology** — from pre-sales handoff to long-term scale. Built in **Adobe Captivate Classic**, originally packaged as SCORM, and republished as a standalone HTML5 build for lightweight web hosting on GitHub Pages.

**🔗 Live Course:** [kitmehta.github.io/Content-Supply-Chain-Genstudio](https://kitmehta.github.io/Content-Supply-Chain-Genstudio/)

---

## 📘 Overview

**Course title:** *From Kickoff to Scale: Implementing Adobe's Content Supply Chain with GenStudio Solution*

The course was designed to give delivery teams (Program Managers, Solution Architects, and Partners) a single, repeatable playbook for running a GenStudio engagement — reducing rework, standardizing the customer experience, and accelerating time-to-value across the engagement lifecycle.

## 🎯 Learning Objectives

By the end of the course, learners can:

- Explain Adobe's 5-phase GenStudio engagement framework and what "good" looks like at each stage
- Apply the critical **Pre-Discovery** checklist before a project ever kicks off
- Run a governance rhythm that satisfies both agile delivery teams and executive stakeholders
- Recognize common engagement "gotchas" and course-correct early
- Understand Adobe-led vs. Partner-led delivery models and how to work within the Partner ecosystem

## 🧩 Course Structure

| Phase | Focus |
|---|---|
| **Pre-Discovery** | System access, legal approvals, discovery guide, risk register, sales-to-delivery handoff |
| **Initiate** | Program charter, delivery roadmap, communication cadence, team evaluation |
| **Discover** | Content Supply Chain workflows, KPIs, business requirements, executive design readout |
| **Create** | Phased build, sprint demos, hands-on validation with the customer's core team |
| **Deploy** | Rollout planning aligned to the Statement of Work |
| **Scale** | Change management, value realization, and long-term adoption |

The course closes with a downloadable **job aid** summarizing the full framework as a quick-reference checklist.

## 🛠️ Tools & Technologies
